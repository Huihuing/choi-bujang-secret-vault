# 워치독스 · 마지막 총공세 7일차 시연·증거 체크리스트

> **작전:** 기록 타임라인형 → 실제 내 PC 측정 → 위험·주의/SDP 출처 구분. **포장 목표:** 공식 앱 묶음 이후 사용자 단위 Inno Setup `setup.exe`. 이 문서는 준비된 시연 안내이며, 실행하지 않은 작업을 완료했다고 쓰지 않는다.

## 1. 직접 시연할 3가지 기능

| 순서 | 화면·수동 조작 | 보여줄 사실 | 주의할 한계 |
|---|---|---|---|
| **1. 기록 보기** | 기존 앱 `http://127.0.0.1:5189/` → **보안 기록** | 서버 자료를 받았다면 발생 시각 최신순, 종류·업무 앱·접속 상태 필터, 사건 상세 버튼 | SDP 서버가 미연결이면 `ENGINE_NOT_CONNECTED`와 확인 불가 안내까지만 사실이다. demo는 실제 서버 기록이 아니다 |
| **2. 내 PC 상태** | 기존 학생 `renderStatus`의 PC 측정 링크 → 별도 `http://127.0.0.1:5191/` → **다시 조회** | 실제 Windows CPU %, 메모리 사용량 GiB, 디스크 여유 GiB 각각의 값·출처·잰 시각. 읽기 실패는 확인 불가 + 이유 | 현재 이 채팅에서 실제 측정 수치가 제공되지 않았다. 화면 예제 숫자는 사용하지 않는다 |
| **3. 주의 알림과 Windows 기록** | 5191 네트워크·방화벽 **다시 조회** → System/Application 필터 → SDP 상태 확인 | 물리 어댑터 수, 방화벽 프로필, 최근 24시간 경고/오류 건수 또는 부분 조회·권한 오류, SDP 미연결 여부를 서로 분리 | 이벤트 경고/오류 건수는 공격·침해 탐지 결과가 아니다 |

## 2. 확인한 것과 아직 확인하지 않은 것

| 구분 | 근거 | 현재 상태 |
|---|---|---|
| **기존 방어전 앱 실행** | 2026-10-26 사용자가 Node.js v24.19.0으로 별도 폴더 clone → 서버 시작 → 종료 → 재시작을 관측함. `STUDENT_RELEASE_REPRODUCTION.md` 참조 | **이전 버전 사용자 실행 확인**, 이번 개선 버전은 별도 |
| **1일차 타임라인** | 학생 `renderEvents`의 정렬·필터 코드, 모의 DOM 검사 | **코드·모의 확인**, 실제 SDP XDR 이벤트 수신 미확인 |
| **2~4일차 실측·조회 UI** | `pc-monitor/collect.ps1`, `server.mjs`, `app.js`; 가짜 JSON 입력으로 버튼·시각·단위·이력·필터·실패 처리 검사 | **코드·모의 확인**, 실제 Windows 측정 미확인 |
| **5일차 타인 실행** | `pc-monitor/INSTALL.md` 제공, 예상 Node 버전/명령 기재 | **독립 사용자 테스트 미확인** |
| **6일차 공식 포장·setup.exe** | 현재 `on-client/package.json`에 `package-app` 스크립트 미등록, 승인된 host/manifest 패키지 검증 불가 | **미완료** |
| **7일차 실화면·제출** | 사용자의 이 개선 버전 스크린샷 및 시험0반용 최종 확인 화면 결과 없음 | **미완료** |

## 3. 실제 캡처와 완성 자료 정리

실제 워치독스에서 **대표 화면 1장**을 캡처한다. 추가로 필요한 경우 최대 6장까지 준비한다. 계정 이름·개인정보·API 키·확인 번호·이벤트 원문 같은 민감 내용은 캡처하지 않는다. 측정값을 캡처한다면 **단위와 측정 시각·출처**까지 보이게 하고, 읽지 못한 항목은 확인 불가 상태를 유지한다.

공식 포장 도구가 준비되면 **동일 버전**의 `finish.commit.raw`, `finish.archive.tar.gz`, `app.zip`, `APP_PACKAGE_MANIFEST.json`을 함께 만든다. 지금은 도구·승인 host·패키지가 없으므로 **네 파일 생성 및 최종 제출을 하지 않았다.** 별도 학생 `pc-monitor/INSTALL.md`는 공식 포장본의 `INSTALL.md`가 아니다. 시험0반 전용 다중 캡처 최종 화면은 진행자가 제공할 때만 사용한다. 기존 「포장 자료 올리기」 칸에 이미지 파일을 대신 넣지 않는다.

## 4. 시연 때 읽을 수 있는 간단한 설명

워치독스는 **기존 SDP 보안 Agent와 Windows PC 자체의 측정값을 구분해서 보여 주는 학습용 앱**입니다. 보안 기록은 서버로부터 자료를 받았을 때 최신순과 종류별 필터로 볼 수 있습니다. 서버가 미연결이면 기록이 안전하다고 단정하지 않고 연결 없음을 표시합니다.

별도 학생용 화면에서는 일반 권한으로 CPU·메모리·디스크 사용 상태를 수동 조회하고 시각·단위를 붙입니다. 실패한 값은 예제 수치로 대신하지 않습니다. 네트워크와 Windows 방화벽 설정도 읽기만 하며, System/Application 경고·오류 건수는 **공격 판정이 아닙니다.** 실제 운영 보안 조치·AI 모델 호출·설치 앱 포장은 검증한 사실이 없어 완료라고 설명하지 않습니다.

## 5. 보존·제출 조건

기존 Git 기록·`public/data.json` 로컬 변경·13~22단계 제출물·운영 자격 설정은 원래 위치에 보존한다. 제공 `src/server.mjs`·`public/app.js`·인증·판정 코드를 수정하거나 보안 기능을 끄지 않는다. 공식 패키징과 Inno Setup은 **기존 `package-app` 명령 및 승인 Host**가 실제로 준비되기 전까지 중단 상태로 둔다. SmartScreen, Defender 등의 보호 설정을 끄라는 설치 안내를 제공하지 않는다.

**릴리스 표현:** 검증 중. 새 UI의 실제 Windows 값·독립 사용자의 실행·앱 패키지·setup.exe·최종 접수는 **미확인 또는 미완료**. v1.0·운영 인증으로 표시하지 않는다.
