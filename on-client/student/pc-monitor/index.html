LOCAL READ-ONLY TELEMETRY

내 PC를 읽고, 상태를 구분합니다.

숫자는 실제 Windows 조회에 성공했을 때만 표시됩니다. 예시 수치는 전혀 표시하지 않습니다. 실패한 값은 확인 불가와 이유를 함께 보여 줍니다.

측정은 아래 다시 조회 버튼을 누를 때만 진행됩니다. 자동 감시·방화벽 변경·이벤트 로그 수정은 하지 않습니다.

DAY 02 · MEASURED

CPU · 메모리 · 디스크

이 PC의 실제 WMI/CIM 조회 결과입니다. CPU의 WMI 스냅샷은 작업 관리자의 순간 사용률과 집계 시각·범위가 다를 수 있습니다.

DAY 03 · READ ONLY

연결 구성과 방화벽 프로필

물리 네트워크 장치 상태·방화벽 설정만 읽습니다. 연결 장치가 있다고 인터넷 접속·보안 적합성을 보장하지 않습니다.

조회 전 · 실제 조회값 없음

WINDOWS EVENT LOG

최근 24시간 경고·오류

Windows 이벤트 경고·오류 건수는 침해·공격 탐지 결과가 아닙니다. System·Application 로그의 Level 3(경고), Level 2(오류)를 조회한 값이며 최대 1000개만 읽은 경우 전체 건수는 확인 불가로 표시합니다.

아직 읽지 않았습니다. 위 「네트워크·방화벽」의 다시 조회를 눌러 주세요.

SEPARATE FROM WINDOWS

기존 보안 Agent · SDP

SDP 상태는 Windows 네트워크·방화벽 조회와 분리합니다. 기존 앱이 실행 중이면 5189번 포트의 /api/diagnostics에서 연결 모드만 확인합니다.
